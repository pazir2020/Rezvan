# داشبورد منابع انسانی رضوان — بسته کامل LAN

این بسته **پروژه کامل** است، نه یک فایل HTML. نسخه بروزرسانی شده روی معماری قبلی:

- FastAPI در `backend/`، بانک PostgreSQL، ورود و مجوزها، APIهای اشتراکی
- HTML داشبورد در `frontend/dashboard-41.html` و سورس قابل بازسازی
- فایل‌های Windows `.bat` و Linux `.sh` در `scripts/`
- آرشیو ماهانه اکسل، صفحه‌های تحلیل و گزارش مرخصی مطابق ساعت:دقیقه اکسل
- ثبت سوابق ماهانه در سرور به صورت Snapshot با وضعیت **imported**، غیرقابل ویرایش و **نه** به‌عنوان تأیید حقوق یا تأیید واریزی بانکی

## برای نصب جدید روی ویندوز

1. Python 3.11+ و PostgreSQL 14+ روی **کامپیوتر سرور** نصب باشد.
2. پوشه `hr_rezvan` را در محل مطمئن باز کنید.
3. `scripts\install.bat` را اجرا کنید و `backend\.env` را طبق README تنظیم کنید.
4. `scripts\first-run.bat` را **فقط برای نصب جدید** اجرا کنید.
5. `scripts\run.bat` را اجرا کنید.
6. سایر افراد روی همان LAN با آدرس `http://IP-Server:8000` متصل شوند.

## ارتقای نصب موجود، بدون از دست دادن داده

1. **اول** `scripts\backup.bat` نسخه سرور فعال را اجرا و خروجی پشتیبان را بررسی کنید.
2. سرور را با `scripts\stop.bat` متوقف کنید.
3. نسخه موجود سرور و `backend\.env` و پوشه اسناد را در جای امن نگه دارید.
4. از این بسته، پوشه `frontend` و فایل‌های `backend/app/specs.py`، `backend/app/services/sync.py` و تست جدید را به نصب موجود منتقل کنید. سایر فایل‌های پروژه و داده‌ها را بی‌دلیل پاک یا بازنویسی نکنید.
5. روی نصب موجود **هرگز** `first-run.bat` یا `restore.bat` اجرا نکنید مگر با تصمیم آگاهانه مدیر سرور.
6. `scripts\run.bat` و سپس آدرس موجود داشبورد را باز کنید.
7. با حساب مدیر منابع انسانی و دارای دسترسی به همه واحدها، یک اکسل ماه واقعی در «آرشیو و ورود اکسل» ابتدا پیش‌نمایش، سپس تأیید کنید.

## نحوه ورود ماهانه

- فقط فایل Excel مشابه فرمت شهریور ۱۴۰۵؛ ماه/سال در شیت‌ها بررسی می‌شود.
- برای وارد کردن، حساب باید `view_salary` و `approve_payroll` و دسترسی **همه واحدها** داشته باشد.
- گزارش مالی وارد شده در جدول `payrollLocks` با `status=imported` و `excelReport` در JSONB سرور ذخیره می‌شود؛ به معنی «پرداخت بانکی تأیید شده» یا «حقوق نهایی تأیید شده» نیست.
- سوابق قبلی بدون اجازه جایگزین نمی‌شوند. داده‌های تأییدشده/قفل‌شده پیشین قابل بازنویسی با ورود اکسل نیستند.
- مرخصی اکسل بر اساس **۱۶ ساعت استحقاق ماه کامل** در فرمول فایل با خواندن مقادیر `[h]:mm` محاسبه و نمایش داده می‌شود؛ ۷:۲۰ یا ۸:۰۰ فقط «معادل روز» است.
- فایل Excel فعلی **داخل ZIP گنجانده نشده** است؛ آن را بعد از استقرار و ورود به سرور بارگذاری کنید، یا اگر اطلاعات از قبل در بانک است دوباره وارد نکنید.

## امنیت و محدودیت‌های آزمایش

- فایل عمومی HTML حاوی لیست کارکنان یا اعداد واقعی حقوقِ از پیش جاسازی‌شده نیست؛ دیتا فقط از API و پس از ورود خوانده می‌شود.
- داده حقوق تاریخی در قفل‌های واردشده فقط به حساب‌های `view_salary` در Bootstrap داده می‌شود. نقش مدیرعامل با مجوز استاندارد پروژه، به جزئیات محرمانه این آرشیو دسترسی ندارد؛ برای نمایش خلاصه مدیریت بدون ارتقای مجوز باید API تجمیع اختصاصی طراحی شود.
- ۶۷ آزمون پایتون اجرا شدند و موفق بودند؛ تعدادی از آزمایش‌های اختیاری مربوط به PostgreSQL/FastAPI و مرورگر واقعی در محیط بررسی در دسترس نبودند.
- سازگاری روی PostgreSQL و شبکه داخلی شرکت **هنوز به‌صورت واقعی آزمایش نشده**؛ قبل از استفاده رسمی، مدیر IT صحت ورود، ثبت، بازیابی و دسترسی نقش‌ها را روی محیط آزمایشی تایید کند.
- فایل ZIP شامل رمزها، کلیدهای نشست، دیتابیس یا اسناد واقعی نیست.

## بازسازی رابط

نسخه HTML از `frontend/dashboard-41.original.html` و `frontend/hr-api-shim.js` ساخته می‌شود:

```
cd frontend
python build_frontend.py
```

صفحه را مستقیم با `file://` باز نکنید؛ باید توسط سرور FastAPI اجرا شود.
