# HRMS رضوان — بازطراحی مرحله اول (LAN)

## تغییرات اجرایی
- صفحه «مرکز فرمان مدیرعامل» از روی داده‌های دریافتی بعد از احراز هویت ساخته می‌شود؛ محتوای اجرایی سرور در HTML جاسازی نشده است.
- فیلتر ماه و واحد سازمانی، شاخص‌های جمعیت فعال، تعداد رکورد حقوق دوره، هزینه تمام‌شده و خالص محاسبه‌شده.
- روند ماهانه هزینه و رتبه‌بندی هزینه واحدها. ماه بدون اطلاعات به‌صورت خالی نشان داده می‌شود، نه صفر.
- میانبرهای مجوزمحور به تحلیل مدیرعامل، ورود اکسل، پرونده، مرخصی، هشدار و حسابداری.
- بازچینی منوها در گروه‌های قابل فهم؛ بخش‌های تخصصی قدیمی در «نمایش گزارش‌های تخصصی قبلی مدیرعامل» باقی مانده‌اند؛ هیچ سوابقی حذف نشده است.
- کنترل دیدن مبالغ فردی/مالی از طریق مجوز view_salary، مستقل از view_ceo.

## موارد حفظ‌شده
- FastAPI، PostgreSQL، فرآیند login، سرور LAN و API همگام‌سازی اصلی.
- ورود فایل ماهانه از همان API بسته قبلی، بدون تغییر قرارداد API.
- موتور مرخصی بر پایه ۱۶ ساعت ماهانه و نمایش ساعت/دقیقه از نسخه قبلی.
- اسکریپت‌های نصب، اجرا، توقف، پشتیبان‌گیری و بازیابی.

## محدودیت‌ها
- این تحویل «مرحله اول اجرای تصویری و معماری منو» است؛ همه ماژول‌های آینده بازنویسی نشده‌اند.
- نمودارهای مالی فقط از اکسل ماهانه ثبت‌شده در سرور استفاده می‌کنند؛ داده قفل‌های حقوقیِ فاقد excelReport در نمودار جدید هنوز تجمیع نمی‌شود و در صفحات تخصصی موجود است.
- گزارش خالص، تأیید واریز بانکی نیست.
- آزمایش با سرور واقعی شرکت انجام نشده است؛ ابتدا روی محیط آزمایشی و با بکاپ انجام دهید.

## نصب بدون تغییر پایگاه داده
1. از پروژه و دیتابیس فعلی پشتیبان بگیرید.
2. ZIP را روی یک پوشه مجزای آزمایشی استخراج کنید؛ فایل `.env` حقیقی و دیتا را از سیستم موجود با بررسی مسئول IT منتقل کنید (پوشه جدید حاوی فقط `.env.example` است).
3. طبق README قبلی نصب و اجرا کنید؛ فرانت‌اند نهایی `frontend/dashboard-41.html` است.
4. با دو نقش مدیرعامل و کارشناس منابع انسانی دسترسی صفحات، فیلترها و محرمانگی را بررسی کنید.
5. بعد از تأیید نتایج و تست بازگردانی بکاپ، نسخه عملیاتی را جایگزین کنید.

## آزمون‌ها
- `PYTHONPATH=backend python -m unittest discover -s backend/tests -q`: ۶۷ آزمون، موفق؛ ۱۴ مورد محیطی skip.
- `node --check` برای JavaScript ماژول طراحی جدید: موفق.
- تأیید نهایی در مرورگر مقابل API و دیتابیس واقعی شرکت: انجام نشده است.
