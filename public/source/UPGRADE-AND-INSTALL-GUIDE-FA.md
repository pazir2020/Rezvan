# راهنمای جامع نصب، ارتقای ایمن و استقرار در شبکه داخلی (LAN) — HRMS رضوان

## ۱. نیازمندی‌های سیستم (روی کامپیوتر سرور رضوان)
* **سیستم عامل:** Windows 10/11 Pro یا Windows Server (یا Linux Ubuntu 22.04+)
* **پایتون:** Python 3.11 یا بالاتر (همراه با PATH)
* **پایگاه داده:** PostgreSQL 14 یا بالاتر (در حال اجرا به عنوان سرویس)
* **مرورگر کلاینت‌ها:** Chrome، Edge یا Firefox بدون نیاز به نصب هیچ فایل یا افزونه‌ای.

---

## ۲. روش ارتقای ایمن سیستم موجود (بدون از دست رفتن اطلاعات)

> **هشدار حیاتی:** اگر پایگاه‌داده `hr_rezvan` از قبل روی سرور شما موجود است، **هرگز** اسکریپت `first-run.bat` را اجرا نکنید. آن اسکریپت صرفاً مخصوص اولین نصب روی سیستم خام است.

### مرحله ۱: تهیه نسخه پشتیبان
قبل از هر تغییری، با اجرای اسکریپت زیر در محیط Command Prompt سرور از پایگاه‌داده و مدارک فعلی پشتیبان بگیرید:
```cmd
cd hr_rezvan
scripts\backup.bat
```
سپس با دستور زیر سلامت فایل پشتیبان را تست کنید:
```cmd
scripts\verify-backup.bat
```

### مرحله ۲: اعمال ارتقای ساختار پایگاه‌داده (غیرتخریبی)
دستور زیر بدون پاک‌کردن جداول یا رکوردهای موجود، تغییرات جدید شامل فیلدهای دوره آزمایشی، حق فنی، و جداول رهگیری تنور را به صورت افزایشی اعمال می‌کند:
```cmd
cd backend
..\.venv\Scripts\python.exe -m app.cli init-db
```

### مرحله ۳: حفظ فایل تنظیمات محرمانه
فایل `backend\.env` شامل رمزهای اتصال دیتابیس است. این فایل نباید با فایل نمونه `.env.example` جایگزین شود.

---

## ۳. راه‌اندازی سرور و دسترسی کاربران در شبکه کارخانه

۱. اجرای سرور با اسکریپت:
```cmd
scripts\run.bat
```
۲. باز کردن پورت ۸۰۰۰ در فایروال سرور (با یک کلیک راست روی `scripts\open-network.bat` و انتخاب **Run as administrator**).
۳. کامپیوترهای دیگر در کارگاه یا دفتر از طریق مرورگر به آدرس زیر متصل می‌شوند:
```
http://IP-SERVER:8000
```
(برای مثال: `http://192.168.1.100:8000`)

## ۴. کاربران پیش‌فرض و نقش‌ها

| نام کاربری | نقش سیستمی | واحد سازمانی | دسترسی‌ها |
|---|---|---|---|
| `admin` | مدیر ارشد سیستم | همه واحدها | دسترسی نامحدود به تمامی بخش‌ها و بکاپ |
| `javad.pazir` | مدیرعامل | همه واحدها | داشبورد ارشد، سناریوها، گزارش‌ها، بدون ویرایش مستقیم پرسنلی |
| `f.soleimani` | مدیر منابع انسانی | همه واحدها | مدیریت پرونده‌ها، حقوق، قراردادها، تایید کارانه |
| `h.ebrahimi` | کارشناس اداری | کارگاه و اداری | ورود کارکرد، مرخصی، ثبت مدارک، بدون مشاهده مبالغ حقوق |
| `supervisor` | ناظر کارگاه | تولید | فقط مشاهده وضعیت سفارشات تنور و کارکرد |

رمز فراموش‌شده با دستور زیر قابل تنظیم است:
```cmd
cd backend
..\.venv\Scripts\python.exe -m app.cli set-password <username>
```
